# ☁️ EduCloud — бұлттық оқу платформасы

**Тақырып:** Бұлттық технологияларды білім беру саласында қолдану
**Орындаған:** Мустафина Алуа Руфатовна

🔗 **Демо:** https://alua30.github.io/educloud/  *(GitHub Pages сілтемесін осында қойыңыз)*

---

## 📌 Жоба туралы

EduCloud — мұғалім мен студентке арналған веб-платформа. Мұғалім тапсырма мен оқу материалын жариялайды, студент оны кез келген құрылғыдан (компьютер, телефон) ашып, жауабын жібереді, ал мұғалім жауаптарды тексеріп баға қояды.

Жобада жеке сервер жоқ: сайт пен деректердің бәрі **бұлтта** орналасқан.

## 🎯 Мақсаты

Бұлттық технологиялардың білім беру процесін қалай жеңілдететінін нақты жұмыс істейтін қосымша арқылы көрсету.

## ☁️ Қолданылған бұлттық технологиялар

| Технология | Бұлттық модель | Жобадағы рөлі |
|---|---|---|
| **GitHub Pages** | Хостинг (PaaS) | Сайтты интернетте тегін орналастыру |
| **Firebase Authentication** | BaaS / PaaS | Email арқылы тіркелу және кіру |
| **Cloud Firestore** | BaaS / DBaaS | Тапсырмалар мен жауаптарды бұлтта сақтау, нақты уақытта жаңарту |
| **Google Drive / YouTube** | SaaS | Оқу материалдарын сілтеме арқылы бөлісу |
| **GitHub** | SaaS | Код пен нұсқаларды бұлтта сақтау |

## ✨ Мүмкіндіктері

**Мұғалім:**
- тапсырма жариялау (тақырып, пән, сипаттама, материал сілтемесі, мерзім);
- студенттердің жауаптарын көру;
- баға қою (0–100);
- тапсырманы өшіру.

**Студент:**
- барлық тапсырмаларды көру;
- жауап жіберу;
- тапсырма күйін көру (жаңа / тексерілуде / бағаланды / мерзімі өтті);
- статистика: тапсырма саны, тапсырылғаны, орташа баға.

Барлық өзгерістер **нақты уақытта** көрінеді: мұғалім тапсырма қосқан сәтте ол студенттің бетінде бетті жаңартпай-ақ пайда болады.

## 🏗 Архитектура

```
 Пайдаланушы (браузер / телефон)
            │
            ▼
   GitHub Pages  ── HTML, CSS, JS файлдары
            │
            ▼
   Google Firebase
     ├── Authentication  (кім кірді?)
     └── Cloud Firestore (users, assignments, submissions)
```

**Дерекқор құрылымы (Firestore):**
- `users` — name, email, role (teacher / student)
- `assignments` — title, subject, description, link, deadline, teacherId
- `submissions` — assignmentId, studentId, teacherId, answer, grade

## 🚀 Іске қосу

1. [Firebase Console](https://console.firebase.google.com)-да жаңа жоба ашу.
2. **Authentication → Sign-in method → Email/Password** қосу.
3. **Firestore Database → Create database** (production mode), **Rules** қойындысына `firestore.rules` мазмұнын қойып, **Publish**.
4. **Project settings → Your apps → Web (</>)** — қосымша тіркеп, `firebaseConfig`-ті `js/firebase-config.js` ішіне көшіру.
5. Репозиторийді GitHub-қа жүктеп, **Settings → Pages → Branch: main** таңдау.
6. **Authentication → Settings → Authorized domains** бөліміне `ЛОГИН.github.io` қосу.
